# AdotaPet

## Descrição do problema
Muitos animais disponíveis para adoção não conseguem visibilidade suficiente, dificultando encontrar pessoas interessadas em oferecer um lar.

## Objetivo
Desenvolver uma aplicação web simples, adaptada para dispositivos móveis, para cadastrar e divulgar animais disponíveis para adoção.

## Funcionalidades previstas
- Cadastrar animais com nome, espécie, idade e características.
- Selecionar uma fotografia do animal.
- Exibir os animais disponíveis para adoção.
- Consultar as informações de cada animal.
- Marcar um animal como adotado.

## Recurso do dispositivo/navegador
Seleção de imagem do dispositivo (galeria/arquivos) para adicionar uma fotografia ao cadastro.
